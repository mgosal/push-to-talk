Parakeet correction viewer

Open a file exported with push-to-talk --export-dataset <file>.
Blocks that carry a recorded audio path get an inline player; click a sentence to jump the audio to its start.

If playback says a recording is missing, click Choose recordings folder and pick the folder the paths live in (e.g. the ptt folder under your temp directory) — browsers block pages from loading local files by path directly, so this grants access explicitly instead.
